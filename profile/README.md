# BlackRoad-OpenAI

> *GPT-powered tools for the highway.*

OpenAI API integration — GPT-4o, embeddings, Whisper transcription, and DALL-E for BlackRoad OS products.

## Usage in BlackRoad
- **Embeddings** — Semantic search for RoadView and memory systems
- **Whisper** — Voice transcription for agent voice interface
- **GPT-4o** — Fallback model in CarPool router
- **DALL-E** — Image generation for BlackBoard creative studio
